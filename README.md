# recycle-nearby

Open-Source-Webanwendung zur Suche nach Recyclingstationen, akzeptierten Materialien und zum Nachverfolgen eigener Recyclingbeiträge.

## Vision

Wir möchten Recycling im Alltag einfacher machen. Nutzerinnen und Nutzer sollen passende Recyclingstationen in ihrer Nähe finden und schnell erkennen können, welche Materialien dort angenommen werden.

## Hauptfunktionen

- Recyclingstationen in der Nähe finden
- Informationen zu den an einer Station akzeptierten Materialien anzeigen
- Eigene Beiträge zum Recycling erfassen und nachverfolgen

## Mitwirken

Das Projekt ist offen für Beiträge aus der Community. Interessierte können:

- bestehende Issues ansehen oder eine neue Idee als Issue vorschlagen
- Fragen und Vorschläge in den Discussions besprechen
- Änderungen über einen Pull Request einreichen

Pull Requests sollen `main` als Zielbranch verwenden und kurz erklären, was geändert wurde. Vor dem Mergen ist eine Prüfung durch eine weitere Person erforderlich.
